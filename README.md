# AAIW_sea_ice_work

## Desciption
This repository contains the Python notebooks and scripts for the project investigating the role of sea ice decline in changing the AAIW water mass properties. The scripts use openly available gridded hydropgraphy products: EN4 (https://www.metoffice.gov.uk/hadobs/en4/download-en4-2-2.html), IAP (http://www.ocean.iap.ac.cn/), and RG-ARGO (http://sio-argo.ucsd.edu/RG Climatology.html).
